# Markdown style

- Write Markdown files to the Google Markdown style guide (https://google.github.io/styleguide/docguide/style.html), unless the file or its repository follows other conventions.
- When a repository defines a Markdown formatter or linter configuration, follow that configuration in place of the style guide and run the formatter or linter after editing.
